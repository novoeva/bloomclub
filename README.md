# AI Bloom Club skills

Skills from the AI Bloom Club workshop for people building their first app.

| Skill | What it does |
|---|---|
| `first-prd` | Turns your rough app idea into a simple one-page PRD: problem, user, first feature, out of scope, and how you'll know it works. |

## Install in Claude Cowork

1. Open **Customize** in the sidebar, then **Plugins**.
2. Choose to add a marketplace from GitHub and paste: `novoeva/bloomclub`
3. Install the **bloomclub** plugin.
4. Start a new task and say: *"Run the first PRD skill."*

When new skills are added here, open the marketplace in Customize → Plugins and click **Update**.

## Install in Claude Code

```
/plugin marketplace add novoeva/bloomclub
/plugin install bloomclub@bloomclub
```
